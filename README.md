# AliceMic

AliceMic - инструкция пользователя

AliceMic превращает телефон в локальный микрофон для Яндекс Станции. Телефон распознаёт слово активации и голосовую фразу, затем передаёт текст выбранной Станции по домашней Wi-Fi сети. Микрофон Станции при этом может быть отключён.

Для работы нужны телефон и Станция в одной домашней Wi-Fi сети, вход в Яндекс-аккаунт, разрешение на микрофон и установленная модель Vosk.

ПЕРВОЕ ПОДКЛЮЧЕНИЕ

1. Откройте раздел «Яндекс».
2. Нажмите «Войти по QR-коду» и отсканируйте код в приложении Яндекс, либо выберите «Войти по ссылке».
3. После подтверждения выберите Станцию в разделе «Ваша Станция».
4. Нажмите «Подключить выбранную Станцию».

Если Станция не отображается, нажмите «Обновить список» и убедитесь, что оба устройства находятся в одной Wi-Fi сети.

МИКРОФОН ДЛЯ АЛИСЫ

Нажмите на строку «Диалог активен» или «Диалог неактивен», чтобы включить или выключить фоновое ожидание слова активации. Когда слово или команда распознаны, главная иконка пульсирует.

При включённом диалоге Android показывает уведомление «Микрофон включён». Это необходимо для фоновой работы и не означает передачу непрерывной аудиозаписи на сервер.

ВАША СТАНЦИЯ

«Подключить выбранную Станцию» подключает выбранную Станцию и включает диалог. «Переименовать выбранную» меняет имя только в AliceMic. «Обновить список» повторно запрашивает Станции и ищет их в локальной сети.

ЭКРАН

«Не отключать экран» не даёт экрану телефона погаснуть, пока открыто приложение. На фоновую работу микрофона настройка не влияет.

МИКРОФОН

«Чувствительность» задаёт программное усиление от 0 до +30 dB. Повышайте её, если речь слышна плохо; слишком высокое значение может усилить шум.

«Уровень микрофона» показывает текущий сигнал и не является настройкой.

«Шумоподавление» уменьшает постоянный фоновый шум. «Автоматическое усиление» самостоятельно подбирает уровень и отключает ручное усиление. «Эхоподавление» уменьшает попадание звука Станции обратно в телефон.

«Записать и прослушать» создаёт короткую тестовую запись и воспроизводит её на телефоне. На время теста голосовой диалог приостанавливается, затем включается снова. Запись хранится во внутреннем кэше и никуда не отправляется.

СЛОВО АКТИВАЦИИ

Введите слово или фразу, например «Алиса», и нажмите «Сохранить слово».

В обычном режиме произнесите слово и команду одной фразой: «Алиса, какая завтра погода?». Для снижения ложных срабатываний слово активации подтверждается распознаванием дважды. Повторять слово пользователю не нужно.

«Режим только слово» сначала ожидает только слово активации, затем включает распознавание команды. Он помогает при ложных срабатываниях. После слова сделайте короткую паузу и произнесите команду.

ДИАЛОГ СО СТАНЦИЕЙ

После команды AliceMic передаёт распознанный текст Станции. Когда Станция ждёт продолжения, следующую фразу можно произнести без слова активации. Пока Станция думает или отвечает, приложение ожидает слово активации; после него отправляется команда «стоп» для прерывания ответа.

ПРОВЕРКА КОМАНДЫ

Введите текст, например «Какая погода завтра?», и нажмите «Отправить на Станцию». Это проверяет подключение без голосового распознавания.

МОДЕЛЬ РАСПОЗНАВАНИЯ

Vosk RU 0.22 нужна для локального распознавания. Кнопка «Скачать русскую модель Vosk» устанавливает её, а «Проверить обновления» проверяет доступность поддерживаемой версии. Перед установкой приложение проверяет контрольную сумму файла.

ПОДДЕРЖКА

«Помощь» открывает эту инструкцию. «Проверить обновления» ищет новую версию приложения на GitHub. «Отправить отчёт» создаёт ZIP-архив, который вы сами выбираете, куда отправить. «Поблагодарить автора» открывает страницу поддержки.

В диагностический отчёт входят версия приложения и Android, модель телефона, разрешения, параметры микрофона и обезличенные категории ошибок. В него не входят аккаунт, токены, адреса сети, Станции, команды, слово активации, аудио и текст журнала.

ЖУРНАЛ

«Показать журнал» открывает технические события: подключение, состояние распознавания и ошибки. На экране хранится до 5 000 символов, поэтому старые записи постепенно заменяются новыми.

КОНФИДЕНЦИАЛЬНОСТЬ

Ожидание слова и распознавание выполняются на телефоне. На Станцию передаётся текст команды, а не непрерывная аудиозапись. Данные входа и токены хранятся через Android Keystore, а соединение со Станцией защищено TLS.
